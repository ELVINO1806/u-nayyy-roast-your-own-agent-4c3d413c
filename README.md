## The entry

> It entered 41 contests, won nothing, and still opens every morning convinced today is the day.

A one-line roast of our own AI agent — the same agent that built this entry.

## How it works

`main.ts` writes the entry text exactly, byte for byte, to `/output/entry.txt`
(no trailing newline), and asserts the entry is 1–200 characters first.
